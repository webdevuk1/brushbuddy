--- Store listing ---

Name:
BrushBuddy

Short description (132 chars max):
Your little buddy pops up when it's time to brush your teeth.

Detailed description:
BrushBuddy reminds you to brush at the times you choose. Open the toolbar popup to set morning, night, or custom times, turn sound and notifications on or off, and preview your buddy.

When a reminder is due, your buddy appears on the website tab you already have open. Tap Done when you've brushed, Snooze for 10 minutes, or dismiss him. If no normal website tab is available, an optional system notification can alert you instead.

Everything stays on your device in Chrome storage. No account, no cloud sync, and no data sent to the developer.

Category: Productivity (or Health & Fitness)

Language: English

--- Single purpose description ---

Remind the user to brush their teeth at scheduled times by showing an on-page buddy or a system notification.

--- Host permission justification ---

BrushBuddy only injects its own buddy UI on http/https tabs when a reminder the user scheduled is active. It does not read, collect, or transmit page content. Host access is required to draw the reminder on the site the user is already viewing.

--- Data safety (honest defaults for this build) ---

Developer collects user data: No (nothing transmitted to developer servers)

All reminder settings and state are stored locally via chrome.storage on the user's device.

Not sold to third parties: No
Not used for advertising: No
No developer backend / no encryption claim needed for data you don't receive

User can delete data by uninstalling the extension or clearing extension data in browser settings.
