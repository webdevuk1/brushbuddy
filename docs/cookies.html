Privacy Terms Cookies
Do you need a cookie pop-up for Brush Buddies? The extension itself does not set website cookies or run ad trackers. You typically do not need a cookie banner inside the extension. If you host these legal pages as plain static HTML with no analytics or ad scripts, you usually do not need a banner on those pages either. If you add Google Analytics, Meta pixels, or similar on your site, you will need a consent tool for UK/EEA visitors.

1. What “cookies” means here

Cookies are small files websites store in your browser. Extensions also use other storage (e.g. Chrome storage.local). This page explains what Brush Buddies uses.

2. Brush Buddies extension

Technology Cookie? Purpose
chrome.storage.local No (extension storage) Save your times, prefs, pending reminder, buddy position
Chrome alarms API No Schedule reminders
On-page buddy script No Show UI on open tabs when a reminder is due; no tracking cookies

Brush Buddies does not use third-party analytics (Google Analytics, etc.) inside the extension and does not set advertising cookies.

3. These legal pages (if you host them on the web)

If you publish privacy.html, terms.html, and this file on GitHub Pages, Netlify, or similar without adding tracking scripts, visitors generally only get essential hosting cookies (if any) from the host — check your host’s documentation.

Do not add analytics to these pages unless you are ready to implement GDPR/UK consent where required.

4. Third parties you choose to visit

If you click an Amazon (or other) link from extension settings, that website may set its own cookies. We do not control those. See Amazon’s cookie notice for details.

5. Chrome / Google

Installing from the Chrome Web Store is subject to Google’s privacy policy. Chrome may sync extension data if you enable sync — that is a Google account feature, not Brush Buddies sending data to the developer.
